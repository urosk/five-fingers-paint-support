# Five Fingers Paint Support Site

Static support and privacy pages for Five Fingers Paint.

## Deployment

- Support: <https://urosk.github.io/five-fingers-paint-support/>
- Privacy: <https://urosk.github.io/five-fingers-paint-support/privacy.html>
- Repository: <https://github.com/urosk/five-fingers-paint-support>

GitHub Pages publishes the repository’s `main` branch root. The deployment repository is separate; do not initialize Git in this folder.

Publish with the `github-pages-support` skill or upload all files to the repository’s `main` branch.

Use the live URLs in App Store Connect and keep `info@bluepeakmobile.com` current.
